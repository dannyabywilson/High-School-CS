# High School CS

A curated selection of ICS3U and ICS4U projects, chosen to show variety across arrays, object-oriented programming, games, graphics, and a practical utility. Source files and project assets are included; generated class files, build output, and IDE state are excluded.

## Selected projects

- **ArraysProject** — Practices storing and working with groups of values using arrays. `ArraysProjectTest` contains the related test project.
- **Animation test** — A small Java project for experimenting with animation and graphics.
- **Basic Animation** — A foundational example of creating motion and visual output in Java.
- **Day 05 Mini Game** — A small interactive game project, bringing together input and control flow.
- **MiniGame2** — A second mini-game project, adding another example of interactive program design.
- **Objects and Instances** — Demonstrates object-oriented programming through classes and instances.
- **TextAndImages** — Combines text and image output in a graphical Java project.
- **Wilson_Animation_Project** — A more developed animation project showcasing graphics and motion.
- **grocery list** — A practical list-management program, adding a utility application to the portfolio.

Where applicable, each project keeps its source code in a separate `src/` folder under the project folder.
